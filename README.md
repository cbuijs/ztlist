# ztlist

NOTE: WORK-IN-PROGRESS and TESTING! USE AT OWN RISK!

Zero-Trust-List - An DNS Domain Apex "allow list" to use in a "block all" environment".

Based on the [Tranco Top List](https://tranco-list.eu/), and stripped NSFW, Ads, Trackers, Social and TIF using the [Hagezi]9https://github.com/hagezi/dns-blocklists) lists.
